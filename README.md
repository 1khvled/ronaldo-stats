## 🌟 Key Features

* **⚡ Career 900+ Goal Tracker:** Real-time countdown and logging on the road to 1,000 official career goals.
* **👑 Champions League Dominance:** Complete stats for the all-time UEFA Champions League top scorer (140 goals, 5 titles).
* **📅 Granular Goal Breakdowns:**
  * Year-by-year and season-by-season analytics.
  * Goals categorized by body part (right foot, left foot, headers).
  * Direct free kicks, penalty kicks, and open-play goals.
  * Real Madrid historic scoring records (450 goals in 438 games).
* **🌍 Multi-Language Support:** Fully localized in English, Spanish (`/es`), French (`/fr`), and Portuguese (`/pt`).
* **⚡ High-Speed Delivery:** Static delivery architecture ensuring sub-100ms response times worldwide.

---

## 🛠️ Tech Stack

* **Core:** Vite, Vanilla HTML5/CSS3, Modern ES6+ JavaScript.
* **Edge & Hosting:** Vercel Edge Runtime & Cloudflare integration.
* **Build Scripts:** Node.js data normalization scripts for career logs.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/1khvled/ronaldo-stats.git
cd ronaldo-stats

# Install dependencies
npm install

# Run the local server
npm run dev
```
